# Инь-Ян — свитчер раскладки для macOS

Значок инь-ян в строке меню. Пока вы печатаете, он следит за словами и сам исправляет
те, что набраны не в той раскладке (`ghbdtn` → «привет», `руддщ` → «hello»).
Когда исправляет — значок делает оборот.

Всё работает локально, без интернета и без нейросетей: системная проверка орфографии
macOS + свои списки частых слов и словарь кода. ~45 МБ памяти, ~0% процессора.

## Как он решает

На каждом пробеле, Enter или Tab берётся последнее слово:

| Набрано | В другой раскладке | Что делаем |
|---|---|---|
| слово | что угодно | не трогаем |
| не слово | слово | меняем и переключаем раскладку |
| не слово | не слово | оставляем вам (опечатка, имя, новый термин) |

Детали:

- **Короткие слова ждут контекста.** `b` может быть «и», а может быть `b`. Решение
  принимается после следующего слова: `b ltkf` → «и дела», `b hello` → `b hello`.
- **Частые слова не трогаются никогда:** «ой» не станет `jq`, «шт» не станет `in`.
- **Знак, нажатый без переключения:** `тестж` → `тест;`, `ghbdtn,` → «привет,». Но «муж»
  и «их» остаются — целое слово всегда важнее.
- **Код и терминал:** пути, почта, ссылки, `--флаги`, `snake_case`, `camelCase` не трогаются.
  Команды, набранные русскими буквами, исправляются: `пше` → `git`, `св` → `cd`.
- В редакторах кода и терминалах короткие слова переводятся на русский только рядом
  с русским текстом: `a + b` останется, а `// b ghjdthrf` станет «// и проверка».
- Поля паролей macOS скрывает сама — там программа ничего не видит.
- Таблица клавиш берётся из ваших раскладок («ABC» + «Русская» или «Русская — ПК»).

## Исправить вручную: двойной Shift

Два быстрых нажатия ⇧ (клавишу можно сменить в меню «Исправить вручную»: двойной ⌥,
правый ⌥ или правый ⌘):

1. **Сразу после автозамены — отменяет её** и возвращает раскладку.
2. **Если что-то выделено — умно инвертирует выделенное:** понятные слова остаются,
   меняются только те, что в другой раскладке становятся словами. Если менять нечего —
   инвертирует всё выделенное.
3. **Иначе — инвертирует последнее слово** (даже если программа сочла его непонятным).

## Обучение

Каждое ручное исправление и каждая отмена — голос. **Два голоса — и слово запомнено.**

- Голоса хранятся **отдельно для каждого приложения и его типа** (код, переписка,
  документы, браузер). Если вы дважды вернули `b` в VS Code, `b` перестанет меняться
  в редакторах кода, но в Telegram по-прежнему станет «и».
- Правило, выученное одинаково в двух типах приложений, становится общим.
- Если слово то меняете, то возвращаете — программа перестаёт трогать его сама.
- Старые голоса со временем весят меньше (вдвое за полгода).
- Список выученного — в меню «Выученные слова», клик по слову забывает его.
- Файл: `~/Library/Application Support/YinYang/learning.json`.

Тип приложения можно поменять в меню («Тип: …»), там же — «Не исправлять в …».

## Установка

1. Скачайте `YinYang.dmg` и откройте его.
2. Перетащите «Инь-Ян» в «Программы» и запустите оттуда.
3. Поставьте галочку: **Системные настройки → Конфиденциальность и безопасность →
   Универсальный доступ → YinYang**.

Приложение не нотаризовано Apple (это платно), поэтому при первом запуске macOS его
заблокирует. Тогда откройте «Системные настройки → Конфиденциальность и безопасность» и
нажмите «Всё равно открыть» — один раз.

Если значка не видно в строке меню, значит, она переполнена и значок спрятался под
вырезом экрана. Запустите «Инь-Ян» ещё раз — меню откроется у курсора. Значок можно
перетащить правее, удерживая ⌘.

## Обновления

Раз в сутки приложение смотрит последний релиз на GitHub. Если версия новее — скачивает
её, проверяет, что она подписана тем же сертификатом, ставит вместо текущей и
перезапускается. Разрешения при этом не слетают. Меню → «Обновления»: проверить сейчас,
выключить автоматическое обновление.

Обновляется только приложение из «Программ» (или другой папки, куда можно писать), а не
запущенное прямо из DMG.

## Выпуск версии

Один раз:

1. Создайте сертификат: `./scripts/make-signing-cert.sh`. Он бесплатный, самоподписанный,
   лежит в `~/.yinyang-signing`. **Сохраните эту папку** (например, в менеджер паролей):
   если её потерять, новые версии будут подписаны другим сертификатом, и у всех
   пользователей не встанет автообновление.
2. В репозитории на GitHub: Settings → Secrets and variables → Actions → New repository
   secret. `SIGNING_P12` — `base64 -i ~/.yinyang-signing/signing.p12 | pbcopy`,
   `SIGNING_P12_PASSWORD` — `pbcopy < ~/.yinyang-signing/password.txt`.

Каждый релиз:

```bash
git tag v0.2.0
git push origin v0.2.0
```

GitHub Actions соберёт `YinYang.dmg` и `YinYang.zip` (Apple Silicon + Intel), подпишет и
выложит в Releases. Через сутки у всех пользователей встанет новая версия.

Собрать DMG локально: `./scripts/make-dmg.sh` → `build/YinYang.dmg`.

## Сборка и запуск

Нужны только Command Line Tools (Xcode не нужен).

```bash
./scripts/build-app.sh
open build/YinYang.app
```

При первом запуске macOS попросит доступ: **Системные настройки → Конфиденциальность
и безопасность → Универсальный доступ → YinYang**. Перехват клавиатуры включится
сам через пару секунд после того, как вы поставите галочку.

Чтобы приложение запускалось само, включите в меню «Запускать при входе»
(лучше сначала перенести `YinYang.app` в «Программы»).

### Чтобы доступ не слетал после каждой пересборки

macOS привязывает разрешение к подписи. Без сертификата подпись меняется при каждой
сборке, и галочку приходится ставить заново. Создайте сертификат один раз —
`./scripts/make-signing-cert.sh`, — и `build-app.sh` будет подписывать им сам
(временной связкой ключей, основную он не трогает).

## Устройство

- `Sources/SwitcherCore` — вся логика без привязки к клавиатуре, покрыта тестами:
  `LayoutMap` (клавиши ↔ буквы), `Scorer` + `Lexicon` (слово или нет),
  `Detector` (решение по одному слову), `TypingSession` (что сейчас на экране, отложенные
  короткие слова, отмена), `SmartConverter` (выделенный текст), `LearningStore` (обучение).
- `Sources/YinYangSwitcher` — приложение: перехват клавиатуры (`KeyboardMonitor`),
  печать за пользователя (`TextInjector`), раскладки (`InputSources`), выделение
  (`SelectionReader`), значок (`StatusIcon`), меню (`AppDelegate`), обновления (`Updater`).

## Известные ограничения

- Программа знает только то, что набрано с последнего клика, стрелок или смены окна.
  Текст, который был до этого, она не трогает — это сделано специально.
- В редких программах замена через Backspace может сбоить (некоторые веб-редакторы
  вроде Google Docs). Для них — «Не исправлять в …».
- В Electron-приложениях (VS Code, Slack, Discord) выделенный текст читается через ⌘C,
  буфер обмена после этого восстанавливается.
- Исправление опечаток пока не делается: в macOS есть своё автоисправление, и два
  исправляющих механизма начали бы мешать друг другу.
